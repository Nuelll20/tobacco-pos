# Tobacco POS Architecture

## Overview

Tobacco POS is a modern Point of Sale (POS) application designed for retail businesses.

The system is initially developed for a tobacco store but is designed to be configurable and reusable for any retail business.

---

## Architecture

The project follows a separated frontend and backend architecture.

Frontend
↓
REST API
↓
Backend
↓
Database

---

## Backend

Framework:
- Laravel 12

Responsibilities:

- Authentication
- Business Logic
- REST API
- Inventory
- Reports
- Transactions

---

## Frontend

Framework:

- React
- TypeScript
- TailwindCSS

Responsibilities

- Dashboard
- POS Interface
- Reports
- Inventory UI
